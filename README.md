# 🚢 Titanic Excel Data Analysis

## 📌 Project Overview

This project analyzes the **Titanic passenger dataset** using Microsoft Excel.

The project focuses on data cleaning, statistical analysis, KPI creation, pivot tables, charts, and dashboard development to understand passenger survival patterns.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Excel Formulas
- Data Cleaning
- KPI Analysis
- Data Visualization

## 📊 Key Analysis

The project analyzes:

- Total passengers
- Total survivors
- Survival rate
- Average fare
- Maximum fare
- Minimum fare
- Survival by gender
- Survival by passenger class
- Passenger age groups
- Fare distribution
- Passenger class distribution

## 📈 Dashboard

The Excel dashboard contains KPIs, pivot tables, and visualizations that provide an overview of Titanic passenger data and survival patterns.

## 🧹 Data Cleaning

The dataset was prepared before analysis by:

1. Checking missing values
2. Handling missing data
3. Checking data types
4. Creating useful calculated fields
5. Preparing the data for Pivot Tables
6. Creating an analysis sheet

## 🎯 Project Objective

The objective of this project is to demonstrate practical Excel skills in:

- Data Cleaning
- Data Analysis
- KPI Creation
- Pivot Table Analysis
- Data Visualization
- Dashboard Development
- Business-oriented insights
